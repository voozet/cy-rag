---
title: Valid Accounts (T1078)
source: MITRE ATT&CK
url: https://attack.mitre.org/techniques/T1078/
section: Technique Description
---
The MITRE ATT&CK Valid Accounts technique (T1078) describes adversaries obtaining and abusing credentials of existing accounts as a means of gaining Initial Access, Persistence, Privilege Escalation, or Defense Evasion. Valid Accounts differs from other techniques in that credential material is legitimate to the environment, so activity performed with a compromised account can blend in with normal usage and evade many detections that focus on malware or unauthorized tooling. Adversaries may compromise credentials of users or services in several ways, including credential phishing, credential dumping from memory or configuration files, brute forcing weak passwords, and purchasing or reusing credentials leaked in prior breaches. ATT&CK defines several sub-techniques covering different account types: Default Accounts (factory-set or pre-configured credentials that are never rotated), Domain Accounts (credentials for accounts managed by Active Directory or similar directory services, which grant access across many systems), Local Accounts (credentials configured by an organization for use on a single system or service), and Cloud Accounts (credentials for services hosted in a cloud environment, such as AWS IAM users or Azure AD accounts). Because a compromised valid account inherits whatever permissions were assigned to it, the impact of this technique scales with the privilege level of the account: compromise of an administrative or service account is significantly more consequential than compromise of a standard user account with limited access. Detection guidance from MITRE emphasizes monitoring for authentication events that are anomalous relative to a baseline of normal account behavior, including logins at unusual times, from unusual geographic locations or network segments, using unusual protocols, or followed by unusual patterns of resource access. Correlating authentication logs with endpoint and network telemetry can help distinguish legitimate account use from an adversary operating under a compromised identity. Mitigations commonly associated with this technique include enforcing multi-factor authentication, applying least-privilege access controls, rotating credentials and disabling default accounts, and monitoring privileged account usage closely.
